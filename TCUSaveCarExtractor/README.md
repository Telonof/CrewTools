# TCUSaveCarExtractor
A command line application designed to extract exported "The Crew Unlimited" saves and turn every owned car and spec into entities to integrate into the game directly.

## Usage
1. Export the desired save via the "TCU Launcher". There should be a new .tcusave file.

2. Drag and drop the save onto this program or add it as an argument inside the terminal. Two files will be generated, an _entities.xml file to be integrated into a PitCrew mod, and a _map.json file.
3. 
The map file has the entities to use in the game on the left hand side along with the original car id on the right to know which car is which.
