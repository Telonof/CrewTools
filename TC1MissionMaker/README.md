# TC1MissionMaker
A semi-automatic CLI mission maker for The Crew.

This tool is designed to read an XML file containing information for custom missions and convert it into a mod that be can installed in a local instance of [PitCrew](https://github.com/Telonof/PitCrew).

Requires any version of .NET Runtime 8 to be installed. 

## Instructions
1. Install .NET Runtime 8, then download the latest version of this tool under Releases and unzip it.

2. Follow the guide found [here](https://github.com/Telonof/CrewTools/wiki/TC1MissionMaker) to make a valid XML file for the mission maker.
> A more guided tutorial to making missions can be found [here](https://modworkshop.net/g/870/document/10).

3. Head into the terminal and call TC1MissionMaker with an argument towards your folder with mission files or just drag and drop the folder onto the executable.

4. Take the .zip file generated where the XML is located and install it as a mod in PitCrew.
