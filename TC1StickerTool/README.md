# TC1StickerTool
A command line application on making brand new stickers (liveries/vinyls) for The Crew 1.

A proper guide on both the images and usage of the tool will be made on the GitHub wiki eventually.

## Usage
1. Follow the guide [here](https://modworkshop.net/g/the-crew/document/how-to-make-vinyls#instructions) or within the download of the program. No guide has been posted outside the TCU discord on making the sticker images themselves yet.

2. Once the root folder with all the images and categories has been made, simply run the program and a mod will be generated in a ZIP file to use with [PitCrew](modworkshop.net/mod/52455).
